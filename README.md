# Eniku Set - Smart Sanitary Pad Vending Machine

A low-cost, IoT-powered sanitary pad vending machine designed to address period poverty, eliminate social stigma, and ensure discreet access in schools and community centers.

## 🌐 Live Web Demo
Explore the user registration and subscription interface:
👉 **[http://enikusetmachine.netlify.app](http://enikusetmachine.netlify.app)**

## ⚙️ Features
- **Low-Cost Hardware Automation:** ESP32 microcontroller controlling three 28BYJ-48 stepper motors with ULN2003 drivers.
- **Privacy-First Dispensing:** 4x4 matrix keypad and 20x4 I2C LCD for anonymous PIN-based collection.
- **Fintech & Subsidy Integration:** Web platform supporting Telebirr and CBE Birr payments (150 ETB / 3 months for 30 pads).
- **Offline Resilient:** Dual-mode cloud verification with local memory fallback.
